## 🧠 Zero-Knowledge & Privacy

I build privacy-preserving systems on Solana:

- **Noir** — writing ZK circuits that prove statements without revealing the inputs
- **Light Protocol v2 ZK Compression** — compressing on-chain state (e.g. nullifiers) while preserving verifiability
- **zk-SNARKs** — succinct proofs for voter eligibility, tally integrity, and one-vote-per-race
- **ElGamal encryption** — confidential ballots with verifiable, privacy-preserving properties

## 🚀 Featured Projects

### 🔐 ZKP Voting System — private, verifiable voting
[![Repo](https://img.shields.io/badge/GitHub-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/MuhKar1/zk-ballot-solana__Anchor-Light-Protocol-V2-ZK-Compression-Noir)

Privacy-preserving, verifiable voting on Solana. **Noir** circuits prove voter eligibility and one-vote-per-race without revealing identity or choice; ballots are **ElGamal-encrypted** and tallied via a verifiable ZK circuit, with nullifiers stored via **Light Protocol v2 ZK Compression**.

### 💧 Solana Decentralised Finance Protocol — AMM, governance & staking
